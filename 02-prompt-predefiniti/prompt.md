# 02 — Dieci prompt da riutilizzare

Questi prompt sono modelli di partenza: aggiungi sempre il tuo obiettivo,
il pubblico, il contesto e il formato che desideri.

## 1. ✍️ La revisora

```text
Controlla questo testo come farebbe una revisora professionista.
Evidenzia errori, parti poco chiare e suggerisci miglioramenti.
```

## 2. 💡 Il brainstorming

```text
Dammi 15 idee diverse su questo tema. Evita le più ovvie e prova a
essere originale.
```

## 3. 📄 Il riassunto intelligente

```text
Riassumi questo testo mantenendo tutte le informazioni importanti,
ma riducendolo del 70%.
```

## 4. 👥 Cambia pubblico

```text
Riscrivi questo testo per un pubblico che non conosce l'argomento.
```

## 5. 🔍 Il feedback costruttivo

```text
Trova i punti deboli di questa idea e proponi possibili soluzioni.
```

## 6. 🗂️ Il piano d'azione

```text
Trasforma questo obiettivo in una lista di azioni concrete,
ordinate per priorità.
```

## 7. ⭐ L'intervista

```text
Prima di rispondere, fammi tutte le domande che ti servono per
aiutarmi al meglio.
```

## 8. 📚 Impara un argomento

```text
Spiegami questo tema in modo progressivo: prima come a una
principiante, poi a livello intermedio, poi avanzato.
```

## 9. 📋 Il verbale

```text
Trasforma questi appunti sparsi in un verbale ordinato, con le
decisioni prese e le attività da fare, ciascuna con il suo responsabile.
```

## 10. 🎯 La collega critica

```text
Agisci come una collega costruttivamente critica. Cerca errori logici,
omissioni e rischi in questo documento. Sii onesta, non compiacente.
```
